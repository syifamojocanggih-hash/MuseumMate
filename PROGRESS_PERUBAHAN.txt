[3] PENERAPAN 4 PILAR PEMROGRAMAN BERORIENTASI OBJEK (OOP)
--------------------------------------------------------------------------------
Semua kelas domain ditempatkan pada package com.museummate.model:

A. Abstraksi (Abstraction):
   - Koleksi.java (Abstract Class): Memuat atribut umum (kode registrasi, nama,
     kategori, asal, tahun perkiraan, bahan, lokasi penyimpanan, kondisi, dll).
   - Method abstrak yang dideklarasikan:
     * public abstract double getFaktorKategori();
     * public abstract int getIntervalPemeriksaanHari();
     * public abstract String getDeskripsiKhusus();

B. Pewarisan (Inheritance):
   - Lukisan.java extends Koleksi
     Atribut tambahan: seniman, teknikMedia, dimensi, adaBingkai.
   - Artefak.java extends Koleksi
     Atribut tambahan: eraDinasti, fungsiObjek, inskripsiOrnamen.
   - Naskah.java extends Koleksi
     Atribut tambahan: bahasa, aksara, alasNaskah, jumlahHalaman.
   - Fosil.java extends Koleksi
     Atribut tambahan: namaIlmiahTaksa, bagianAnatomi, formasiGeologi.

C. Polimorfisme (Polymorphism):
   - Meng-override method getFaktorKategori() dengan nilai spesifik PRD 6.4:
     * Naskah: Faktor 1.5 (risiko bahan organik tertinggi)
     * Lukisan: Faktor 1.2
     * Artefak: Faktor 1.0
     * Fosil: Faktor 0.8
   - Pemetaan polimorfik saat pemuatan dari database (KoleksiDAO.java).
   - Method hitungSkorPrioritas() pada Koleksi menghasilkan skor yang berbeda-beda
     secara otomatis sesuai objek turunan aslinya.

D. Enkapsulasi (Encapsulation):
   - Seluruh atribut dibuat 'private'.
   - Akses melalui getter dan setter dengan validasi ketat (mencegah field wajib
     kosong, pencegahan tanggal pemeriksaan di masa depan, dll).
   - Dibuat Enum terstruktur:
     * KategoriKoleksi.java
     * KondisiKoleksi.java (Bobot: Baik=1, Cukup=2, Rusak Ringan=3, Rusak Berat=4)
     * PeranPengguna.java (ADMIN, KONSERVATOR)
     * StatusJadwal.java (DIRENCANAKAN, SELESAI, DIBATALKAN)
   - DTO untuk antarmuka antrian: PrioritasItem.java.

[5] LAPISAN LOGIKA BISNIS (SERVICE)
--------------------------------------------------------------------------------
Package com.museummate.service:
- AuthService.java:
  Validasi username & verifikasi hash password dengan jBCrypt, manajemen sesi aktif.
- PrioritasService.java (Fitur Utama Pembeda MuseumMate - PRD F6 & 6.4):
  Engine kalkulasi skor prioritas dinamis:
  Skor = (Bobot Kondisi x 10) + (Hari Terlewat / 30) x Faktor Kategori
  * Menghitung hari terlewat sejak pemeriksaan terakhir.
  * Jika belum pernah diperiksa, menggunakan tanggal diterima sebagai acuan hitung.
  * Mengurutkan seluruh koleksi dari skor tertinggi ke terendah secara dinamis.
- KoleksiService.java:
  Validasi data inti, pengecekan keunikan kode registrasi, pengecekan riwayat.
- PemeriksaanService.java:
  Validasi tanggal (tidak boleh di masa depan) dan pencatatan riwayat fisik.
- JadwalService.java:
  Penyusunan jadwal, pembaruan status, dan pelacakan jadwal lewat batas waktu.
- DashboardService.java:
  Agregasi metrik total koleksi, sebaran kategori, sebaran kondisi, dan top prioritas.
- LaporanService.java:
  Ekspor berkas PDF resmi (A4 Landscape) menggunakan OpenPDF untuk:
  1. Laporan Inventaris Koleksi Museum
  2. Laporan Daftar Prioritas Tindak Lanjut Konservasi

[9] PERBAIKAN MASALAH / BUG FIXING
--------------------------------------------------------------------------------
- Masalah: Login sempat memunculkan "Username atau password salah".
- Analisis: Variabel tanda dolar ($2a$10$...) pada hash BCrypt di skrip SQL
  sempat terpotong saat dieksekusi melalui powershell double-quoted string.
- Solusi:
  * Menghasilkan hash valid langsung menggunakan utilitas jBCrypt.
  * Memperbarui tabel 'pengguna' di basis data aktif Laragon.
  * Menyinkronkan hash permanen pada seed_data.sql, setup_database.sql, dan
    DatabaseConnection.java. Akun demo admin & konservator kini dapat langsung
    digunakan tanpa kendala.
